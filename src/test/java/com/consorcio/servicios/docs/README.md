# Pruebas

Este directorio contiene los detalles de las pruebas unitarias y de integracion realizadas para el proyecto de gestion del consorio de agua santa maria de oro.

## Configuración Inicial

Antes de ejecutar estas pruebas, asegúrate de que todas las dependencias estén instaladas correctamente. Las pruebas se ejecutan en un entorno de prueba aislado para evitar efectos secundarios en la base de datos.
